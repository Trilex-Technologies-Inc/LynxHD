Task Manager Guide

1. Install Task Manager from the Modules page.
2. Open Task Manager from the Modules menu.
3. Select New task, enter a title, priority, due date, and assignee.
4. Use Open, Overdue, Completed, and All to filter the list.
5. Mark a task complete from its check button, or reopen it later.
6. Edit changes task details. Delete permanently removes the task.

Disabling hides Task Manager without deleting tasks. Uninstalling permanently removes all task data.
