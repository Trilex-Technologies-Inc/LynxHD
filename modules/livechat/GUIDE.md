Live Chat Guide

1. Install and enable Live Chat from the Modules page.
2. Open Manage and enable the customer chat box.
3. Visitors enter their name, email, and department before starting.
4. Select a conversation to reply. Use Canned for saved responses.
5. Close ends a conversation. Block user also prevents new chats from the same session, email, or IP address.
6. Manage reusable replies in the Canned messages section.

Uninstalling Live Chat permanently removes its conversations, messages, canned replies, and blocked-user records.
